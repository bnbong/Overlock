# Claude 작업 지시: Overlock 조향 감도 체험 트랙

이 저장소의 `docs/sensitivity-calibration-plan.md`를 먼저 읽고 그 계획을 구현해 주세요. 목적은 새 사용자가 첫 Start에서 데모 트랙을 달리며 기존 조향 감도를 조절하고, 공식/유저 트랙 선택 화면에서 언제든 다시 체험할 수 있게 하는 것입니다.

핵심 요구사항:

1. 첫 실행 때 닉네임 모달이 표시된 사용자만 닉네임 저장 후 **첫 Start**에서 데모로 자동 입장합니다. 기존 닉네임이 저장된 설치는 기존 Start 흐름을 유지합니다. 닉네임 저장과 Start 사이에 앱을 재실행해도 의도가 보존되도록 `user://settings.json`에 대기 상태를 저장하고, 키가 없는 기존 설치를 안전하게 처리하세요. 첫 자동 입장 뒤에는 일반 Start로 돌아갑니다.
2. 데모에서는 현재 `TutorialDialog`를 **입장할 때마다** 띄우고, 코스에서 감도를 맞추며 설정에서도 언제든 바꿀 수 있다는 설명을 넣으세요. 기존 일반 첫 플레이 튜토리얼 동작은 유지하세요.
3. 데모 HUD에서 현재 감도를 라이브 조절하세요. `Tuning.steer_expo`와 `LeaderboardClient.save_steer_expo()`를 재사용하고 기존 설정 화면과 동일한 0~100% 매핑, 0.25~0.65 범위를 쓰세요. 낮은 값은 반응 빠름, 높은 값은 부드러움으로 올바르게 표기하세요. 마우스·터치·키보드가 모두 쓸 수 있어야 하며 키보드 감도 조절이 운전 입력과 충돌하지 않아야 합니다. 저장 실패도 사용자에게 보이게 하세요.
4. `TrackKindSelectScreen`의 공식/유저 카드 아래에 **감도 다시 맞추기** 버튼을 넣으세요. 포커스 이동, 뒤로 가기, 1280×720과 844×390 가로 모바일 배치를 함께 정리하세요.
5. 단순 좌우 S구간과 드리프트 연습 코너가 있는 짧은 면 원단 데모 JSON을 만드세요. 아이템과 modifier는 두지 않고 `TrackValidator` 및 실제 주행으로 코스를 확인하세요. 데모는 공식 manifest, 커스텀 목록, 온라인 제출 대상에 넣지 마세요.
6. 데모의 완료/완주/중도 종료는 종류 선택 화면으로, 다시 달리기/R은 데모 시작점으로 보냅니다. 데모는 기록·고스트·Result·리더보드에 영향을 주면 안 됩니다. 일반 주행과 에디터 테스트 경로는 유지하세요.

구현 전 `MainMenu`, `NicknameDialog`, `LeaderboardClient`, `GameState`, `TrackLoader`, `RaceDirector`, `TutorialDialog`, `HUD`, `TrackKindSelectScreen`, `SettingsScreen`의 실제 호출 흐름을 확인하세요. 특별한 사유가 없으면 기존 UI 스킨과 설정 저장 API를 재사용하고 새 의존성이나 별도 설정 저장소는 추가하지 마세요. `docs/sensitivity-calibration-plan.md`의 완료 기준을 검증하는 작은 회귀 검사를 기존 테스트 도구에 추가하고, 관련 테스트 실행 결과와 남은 제약을 최종 보고에 적어 주세요.
