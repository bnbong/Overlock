# Overlock 홍보 영상

이 디렉터리에는 Overlock 홍보 영상 완성본과 편집 자료가 들어 있습니다. 영상은 현재 빌드를 촬영한 게임 화면에 재봉 모티프 모션 그래픽을 입히고, 모든 컷과 자막을 음악의 박자에 맞춰 배치했습니다.

## 구성 요약

음악은 Kevin MacLeod의 "Newer Wave"(110 BPM)에서 45.856초부터 20마디(80박)를 잘라 썼습니다. 영상의 0초가 이 구간의 첫 강박이며, 1박은 0.5455초이고 1마디는 2.182초입니다.

## 다시 만드는 방법

제작 도구는 `tools/promo/video/`에 있습니다. 파이썬 가상 환경을 하나 만들고 아래 명령을 저장소 루트에서 실행하면, 이 디렉터리의 산출물이 모두 다시 만들어지고 검증까지 수행됩니다.

```bash
python3 -m venv /path/to/venv
/path/to/venv/bin/pip install numpy pillow scipy soundfile librosa skia-python

PY=/path/to/venv/bin/python WORK=/path/to/scratch POSTER_FRAME=1110 \
  tools/promo/video/build.sh all
```

- `build.sh video`는 렌더와 인코딩만 수행하고, `build.sh verify`는 검증만 수행합니다.
- 중간 파일(음악 WAV, 영상 단독 트랙, 디버그 렌더, 검증 JSON)은 `WORK`에만 쓰이고 저장소에는 들어가지 않습니다.
- 제작에 사용한 macOS 환경에서 1080p 렌더는 약 2분 40초가 걸렸습니다. 검증용 디버그 렌더도 비슷한 시간이 걸립니다.
- macOS에서는 AudioToolbox AAC 인코더(`aac_at`)를 사용합니다. 이 인코더가 없는 환경에서는 ffmpeg 내장 `aac`로 바뀌는데, 이 곡에서는 내장 인코더가 트루피크를 약 3dB 올렸으므로 라우드니스 수치를 다시 확인해야 합니다.

## 편집 방식

- 편집 타임라인은 `tools/promo/video/timeline.json`에 비트 번호로만 적혀 있습니다. 초와 프레임은 `music/beatmap.json`의 비트 목록에 직선을 맞춘 격자(주기 0.545459초, 잔차 최대 0.5ms)에서 계산합니다. 따라서 타임라인에 초 단위 값을 직접 적지 않습니다.
- `render.py`는 촬영본을 BT.709 리미티드 레인지로 정확히 디코딩한 다음 skia로 모션 그래픽을 합성하고, 결과 프레임을 곧바로 x264에 넘깁니다. 중간 인코딩을 거치지 않으므로 화질 손실은 최종 인코딩 한 번뿐입니다.
- 촬영본의 속도를 바꿀 때는 프레임을 섞지 않고 원본 60fps 프레임 가운데 하나를 골라 씁니다. 그래서 잔상이 생기지 않습니다. 카운트다운(약 1.8배), 가속 구간(약 1.19배), 완주 줌아웃(약 1.15배)에 이 재매핑을 적용해서 숫자 전환, 기어 변경, 등급 표시가 박자 프레임에 정확히 떨어지도록 했습니다.
- 촬영본 확대는 최대 1.22배입니다. 박자마다 들어가는 줌 펀치는 강박에서 4.5%, 약박에서 1.4%이고 드롭(16박)에서만 10%입니다.
- 전체 화면 섬광은 드롭(16박)과 재진입(64박) 두 번뿐입니다.
- 촬영 환경에서 생긴 '오프라인' 표시는 메뉴 카드를 자를 때 잘라 냈고, 완주 화면 하단의 'Press any key to continue' 문구는 화면 하단을 배경색 그라데이션으로 덮어 가렸습니다.
