![Overlock 원페이지](overlock_onepager.png)

재봉틀 노루발을 레이싱 머신처럼 몰아 원단 위 재봉선을 정확히 박는 무료 웹 타임어택 게임.

- **플레이**: https://overlock.bnbong.com (데스크톱 브라우저 권장)

## 특징

- 조작 두 가지 - 속도 & 방향
- 재봉선을 얼마나 정직하게 따라갔는지가 실력
- 고속 급조향 시 손가락 부상
- 공식 트랙 10 - 하트, 고양이, F1 참고 서킷 등
- 트랙 에디터 · 파일 공유 · 온라인 리더보드

## 조작법

| 키 | 동작 |
| --- | --- |
| ←→ / A D | 조향 |
| ↑↓ / W S | 속도 |
| R | 재시작 |
| Shift (홀드) | 드리프트 |
| Esc | 일시정지 |
