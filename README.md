## 게임 하기

- 공식 사이트: https://overlock.bnbong.com/
- itch.io: https://bnbong.itch.io/overlock

Overlock은 재봉틀 노루발을 레이싱 머신처럼 몰아 원단 위 재봉선을 따라 달리는 무료 웹 타임어택 게임입니다. 빠르게만 달리면 등급이 떨어지고, 급하게 꺾으면 손가락을 다칩니다. 정직하게 박을수록 높은 등급을 받습니다.

<details>
<summary>조작 키 표 보기</summary>

| 입력 | 기능 |
|---|---|
| `←` / `A` | 왼쪽 조향 |
| `→` / `D` | 오른쪽 조향 |
| `↑` / `W` | 속도 단계 상승 |
| `↓` / `S` | 속도 단계 하락 |
| `⇧ Shift` (홀드) | 피벗 드리프트 |
| `Space` | 보관한 아이템 사용 |
| `R` | 재시작 |
| `Esc` | 일시정지 |

</details>

## 참고

- 데스크톱 브라우저에서 플레이하는 것을 권장합니다.
- 모바일에서는 화면에 표시되는 터치 버튼으로 조작하며, 가로 화면으로 플레이해야 합니다.
- 로컬 기록과 고스트는 브라우저에 저장되며, 사이트마다 따로 관리됩니다. 공식 사이트와 itch.io의 로컬 기록과 고스트는 서로 공유되지 않습니다.
