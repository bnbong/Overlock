# 원단에 밀착된 손과 확대 노루발 에셋

이 디렉터리의 PNG는 `docs/concepts/ingame-palm-contact-v1.png`를 바탕으로 내장 `image_gen`에서 생성했습니다. 기존 게임 에셋의 색상과 선화를 참조했습니다. 손목을 낮추고 손바닥을 원단에 붙이는 자세로 바꾸었으며, 노루발은 바늘이 없는 독립 파츠입니다.

구현 계획은 `docs/ingame-palm-contact-plan.md`, 실제 생성 프롬프트는 `docs/concepts/palm-contact-assets-prompts.json`에 있습니다. 생성 원본을 기존 파일에 덮어쓰지 않고 이 디렉터리에 보관합니다. 게임 코드의 연결과 최종 화면 조정은 Claude Fable의 구현 작업에서 진행합니다.

| 파일 | 상태 |
|---|---|
| `hand_flat.png` | 기본 손 |
| `hand_mom_flat.png` | 버건디 니트 소매를 입은 엄마 손 |

## 배치 계약

- 손은 화면 오른쪽 기준 방향입니다. 화면 왼쪽은 `HandView.mirror=true`로 반전합니다. 손등과 손톱이 카메라 쪽을 향하고, 손바닥은 아래를 향합니다.
- 손 원본의 기준 캔버스는 1448×1086입니다. 노루발은 1254×1254입니다. 고해상도 이미지를 원본 크기 그대로 그리지 말고 공통 표시 사각형으로 그립니다.
- 손 상태마다 불투명 영역을 잘라 중심을 재계산하지 않습니다. 소매와 골무 때문에 경계가 달라집니다. 이미지의 투명 여백을 포함한 같은 사각형을 사용합니다.
- 생성 이미지 사이의 세부 음영은 완전히 동일한 픽셀이 아닙니다. 최종 표시 크기에서 손끝과 손목이 움직이는 것처럼 보이지 않는지 전환 검증을 합니다.
- 노루발의 중앙 U자 슬롯과 배경은 투명합니다. 내려간 바늘 끝이 슬롯 안의 원단에 닿도록 표시 사각형을 정렬합니다. 긴 바늘대는 별도 렌더링하고 이 PNG 전체를 왕복시키지 않습니다.
- 접촉 그림자는 원단 재질과 손 상태에 맞춰 게임에서 그립니다. 생성 에셋에 원단이나 큰 드롭 섀도를 넣지 않았습니다.
- 모바일 메모리를 줄이려면 손에는 공통 import 크기 제한 768px, 노루발에는 512px를 시작값으로 검토합니다. 소스 PNG는 유지하고 import 설정과 실제 선명도를 함께 확인합니다.

## 에셋 검증 범위

PNG 크기와 알파 채널을 확인하고, Godot 4.6.1의 `Image`로 로드해 배경 및 노루발 슬롯의 실제 투명도를 검사합니다. 생성 이미지에서 손가락 수와 부상·골무 위치를 시각적으로 확인합니다. 검사 결과는 `docs/concepts/palm-contact-assets-validation.txt`에 기록합니다.

이 검사는 실제 게임 배치·애니메이션·모바일 실기 검증을 대신하지 않습니다. 그 항목은 구현 계획의 완료 조건을 따릅니다.
